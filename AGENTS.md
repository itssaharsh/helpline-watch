# AI-assisted development disclosure

This project was built with Claude Code (Anthropic) driving the editor and shell, with
the author reviewing, running and testing every change. Specifically:

- Idea selection and research (hackathon rules, scam reports, TRAI/RBI references) were done with Claude Code and web search; figures are cited in the README with sources.
- Backend and frontend code, tests, fixtures and docs were written with Claude Code; `make verify` and the test suite are the acceptance gate.
- No AI model runs inside the product. Verdicts are deterministic (see `docs/adr/0002-deterministic-signals-no-llm.md`).
- The synthetic demo fixtures were generated by `backend/scripts/make_synthetic_fixtures.py`; phone numbers in them are made up.
